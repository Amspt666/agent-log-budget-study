# Numerical evidence for the log-budget study

Author: Hongming Guo. This archive contains 9,450 scored outcomes, aggregate estimates, sensitivity checks and numerical reproduction scripts. It contains no raw prompts, response bodies or API credentials. The upstream benchmark is not redistributed here.

Download log_budget_evidence_v1.zip and extract it. Run `python reproduce_scored_evidence.py --evidence .` from the extracted directory. The checks reproduce numerical results from scored outcomes, not historical API responses. Detailed definitions and limitations are in README.md inside the archive.
